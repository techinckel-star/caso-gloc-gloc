# Verificação das afirmações

| ID | Afirmação | Fonte | Resultado |
|---|---|---|---|
| A1 | A Constituição protege intimidade e vida privada | Constituição Federal | CONFIRMADA |
| A2 | A Constituição prevê proteção de dados pessoais | Constituição Federal | CONFIRMADA |
| A3 | A LGPD disciplina o tratamento de dados pessoais | LGPD | CONFIRMADA |
| A4 | O caso permite determinar automaticamente a base legal utilizada pela empresa | Nenhuma | NÃO CONFIRMADA |
| A5 | Todos os dados devem necessariamente ser eliminados | Nenhuma | NÃO CONFIRMADA |
| A6 | É necessário analisar a finalidade e a situação dos dados antes de uma resposta definitiva | LGPD / análise do caso | REQUER REVISÃO HUMANA |

## Observação

A verificação não deve considerar uma afirmação verdadeira apenas porque
ela parece juridicamente plausível.

É necessário localizar fundamento na fonte selecionada.
