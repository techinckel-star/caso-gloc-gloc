# Resposta inicial

## Fatos relevantes

A CANDIDATA_A solicitou à EMPRESA_FICTICIA a exclusão de dados pessoais
relacionados a um processo seletivo.

Os dados mencionados no caso incluem informações cadastrais, currículo,
anotações de entrevistas e registros administrativos.

## Questões jurídicas identificadas

A análise deve considerar:

1. quais dados pessoais estão sendo tratados;
2. para quais finalidades os dados foram coletados;
3. qual fundamento jurídico foi utilizado para o tratamento;
4. se existe solicitação relacionada aos direitos do titular;
5. se existem razões jurídicas para conservação de determinados dados;
6. quais informações devem ser efetivamente eliminadas, caso aplicável.

## Fundamentos encontrados

A Constituição Federal reconhece a proteção da intimidade e da vida privada
e também prevê proteção e tratamento de dados pessoais.

A LGPD estabelece regras específicas para o tratamento de dados pessoais e
disciplina direitos dos titulares e obrigações relacionadas ao tratamento.

## Pontos não confirmados

As fontes selecionadas não permitem determinar, somente a partir do relato,
qual foi a base legal utilizada pela EMPRESA_FICTICIA para cada operação
de tratamento.

Também não é possível concluir apenas com o relato quais documentos ou
registros possuem obrigação legal de conservação.

## Orientação inicial

Antes de responder definitivamente à CANDIDATA_A, recomenda-se identificar:

- os dados efetivamente armazenados;
- a finalidade de cada tratamento;
- a base jurídica correspondente;
- eventuais obrigações de conservação;
- quais dados podem ser eliminados;
- quais dados, caso devam ser conservados, possuem justificativa documentada.

A resposta definitiva deve ser submetida à revisão humana.

## Limitação

Esta resposta foi produzida para fins acadêmicos e não constitui parecer
jurídico.
