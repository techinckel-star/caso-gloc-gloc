# Orientação inicial revisada

## Caso

A EMPRESA_FICTICIA recebeu uma solicitação da CANDIDATA_A para exclusão
de seus dados pessoais utilizados em processo seletivo.

## Orientação

A análise não deve começar pela eliminação automática de todos os registros.

Primeiro, deve ser realizado um levantamento dos dados existentes e das
respectivas finalidades de tratamento.

Também devem ser identificados os fundamentos utilizados para cada tratamento
e eventual necessidade de conservação de determinados registros.

A solicitação deve ser analisada à luz dos direitos previstos na legislação
de proteção de dados, considerando as circunstâncias concretas.

## Procedimento recomendado

1. localizar os dados relacionados à CANDIDATA_A;
2. classificar os dados encontrados;
3. identificar a finalidade de cada tratamento;
4. identificar o fundamento utilizado;
5. verificar se existe necessidade de conservação;
6. separar os dados que podem ser eliminados;
7. registrar a decisão;
8. preparar resposta ao titular;
9. submeter a resposta à revisão humana.

## Limitações

A documentação disponível no exercício não permite concluir que todos os
dados devem ser eliminados nem que todos devem necessariamente ser mantidos.

Essa conclusão dependeria de informações adicionais sobre o tratamento
realizado pela organização.

## Revisão humana

A orientação foi revisada após a resposta inicial e a auditoria.

Este documento possui finalidade exclusivamente acadêmica.
