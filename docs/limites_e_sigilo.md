# Limites, sigilo e sanitização

## Natureza do projeto

Este projeto possui finalidade exclusivamente acadêmica.

O caso jurídico é fictício e não representa uma pessoa ou organização real.

## Dados pessoais

Nenhum dado pessoal real deve ser inserido no repositório.

Os dados existentes em `entrada/relato_bruto.md` são simulados.

## Sanitização

Antes de qualquer consulta ao RAG, o relato deve passar pelo processo de
sanitização.

A identificação utilizada após a sanitização é:

- CANDIDATA_A
- EMPRESA_FICTICIA

## Limitação da resposta

A resposta produzida pelo sistema não constitui parecer jurídico real.

O fluxo tem finalidade demonstrativa e deve ser submetido à revisão humana.

## Regra de segurança

Caso apareçam dados pessoais não necessários à análise, eles devem ser
removidos ou substituídos antes da utilização no RAG.
