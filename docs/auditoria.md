# Prompt de auditoria

Analise a resposta produzida pelo RAG.

Verifique individualmente cada afirmação jurídica relevante.

Para cada afirmação, registre:

- afirmação;
- fonte indicada;
- localização da fonte;
- confirmação encontrada;
- resultado: CONFIRMADA / NÃO CONFIRMADA / EXTRAPOLADA.

Também verifique:

1. se foram utilizadas somente as fontes autorizadas;
2. se houve criação de informação inexistente;
3. se houve citação incorreta;
4. se houve exposição de dados pessoais;
5. se a resposta ultrapassou os limites do caso;
6. se existe algum ponto que obrigatoriamente precisa de revisão humana.

Não corrija silenciosamente a resposta.

Toda divergência deve ser registrada para permitir auditoria posterior.
